# 《山羊对撞》美术风格指南 v1（2026-10-29，Game Art Director）

> 只约束画面。物理相关（碰撞框、画布尺寸、锚点、帧数、部件拆分）一律以 `art/manifest.json` / `parts.json` 为准，美术不得改动。颜色见 `palette.md` / `palette.json` / `palette.gpl`。

## 1. 两套语言，一个画面
| 层 | 风格 | 关键词 |
|---|---|---|
| 山羊（角色） | 半写实，像真山羊 | 侧面朝右、真实比例、羊毛略松散蓬、有山羊胡 |
| UI | 仿国内版羊了个羊 | 草绿底 #CFFC98、白填充、粗墨绿黑描边 #2F3727、硬投影、简约可爱 |

角色不加 UI 那种粗黑描边；UI 不加写实光影（theme.js：无暗角/无渐变）。

## 2. 山羊
- 参考：`base_side_realistic.png`（侧面朝右）。
- **羊毛**：灰度 mask，运行时乘色（6 色见调色板）。蓬松边缘允许簇状小毛，但不得出现半透明雾边（见报告：cloud 半透明边缘像素比 fluffy 多 67%）。
- **胡子规则**：胡子是灰度 mask，与羊毛**同色**相乘；层次比羊毛整体亮（均值 ≈228 vs 羊毛 ≈197），最亮不超过 ~254。禁止画成固定棕/黑色。
- **羊角**：灰度 mask，中灰 128 = 目标色，亮部高光、暗部纹理；4 种形状 curl/straight/spiral/branch。
- **身体/蹄/脸**：彩色原样，不换色。身体深棕 #4C341C–#6C4C2C，脸 #AC8C6C，眼鼻 #140404。
- **腿**：v10.1 起四条腿均有补丁层（`parts/*/leg_*_patch`）；膝补丁绘制在羊毛之上（旧报告 P4 已撤回）。

## 3. 光源
统一**左上方偏上**主光（测得：fluffy_idle 上半亮度 211 vs 下半 181；body_idle 上 96 / 下 58）。羊角当前右侧更亮（右 127 / 左 99），属于沿角朝向的高光，新角保持“上亮下暗”即可。不画投射阴影；游戏内只加脚下接触阴影 `#2F3727` α0.26。

## 4. 描边
- 角色：无硬描边，靠明暗分形；外缘抗锯齿 1–2 px，**禁止残留绿幕色**（G 比 R、B 高 >25 视为绿边）。
- UI：750 宽样稿中按钮描边 4 px、面板 5 px、标题字描边 10–14 px，投影 7–12 px 实心 #2F3727（`ui_mock_v2/build.py`）。游戏内 375 逻辑宽对应减半（2 / 2.5 / 5–7 px）。

## 5. 画布与对齐（只读）
- 大图 1152×1024、小图 360×320（缩放 0.3125），所有层共用画布，左上角叠放；anchor 为脚底中心（idle 511,995）。共 39+39 张，实测无尺寸异常。
- 绘制顺序：wool → knee → body → beard → face → horn。

## 6. 手机可读性
- 胡子小图（_320）v10.1 已加大：不透明像素 idle 156 / jump 99 / clash 134，作为下限，新胡子不得低于此。
- 羊角形状靠剪影区分：在 64 px 高缩略下 4 种角要一眼可辨。
- UI 文字白字+粗描边，最小 24 px（750 稿）。颜色只给可点击的东西。

## 7. 命名
`{类别}/{变体}_{姿态}.png` + `_320` 小图；姿态只用 idle / jump / clash。补丁：`{wool}_{pose}_a{角度}.png`。

## 8. 反馈文字与区域（v10.1 决策）
- 「完美！」：38 px，白色外描边 #FFFFFF（不用墨绿黑描边，以便压在山羊/草地上都可读）。
- 完美区描边：accentYellow #FCD800。
- 教学奖励羊毛：薰衣草紫 #CDB8F0，与其他羊毛色同为乘色。
- 可接受偏差：idle/spots/白色组合渲染多出 1 px 透绿，已接受，不再追修。
- 延后到上线后：spots_mask 孔洞、蹄部小孔。
