# 01 角力推理线索库

> 和原型对齐：角度 `ang ∈ low/mid/high`（main.js 中的 ANG）；角形 `horn.id ∈ curl/straight/spiral/branch`，`horn.win` 表示该角形克制的角度（data.js）。数据文件：data/clues.json。

## 1. 玩法一句话
起跳前对手做出"架势"，同时给出若干条线索，其中可能混有假动作。玩家在观察时间内**预判对手真正的角度**（低/中/高），然后照常点力量条起跳。

## 2. 架势分类（架势 = 对手真实角度 × 风格）
| 架势 id | 真实角度 | 名称 | 常见角形 | 说明 |
|---|---|---|---|---|
| `low_charge` | low | 低头冲锋 | curl | 压低身子从下往上铲 |
| `low_sweep` | low | 贴地扫角 | branch | 横扫，力量大 |
| `mid_ram` | mid | 正面顶撞 | spiral | 平直冲撞 |
| `mid_feint` | mid | 侧身试探 | 任意 | 线索最模糊，高段位常用 |
| `high_leap` | high | 高跳下劈 | straight | 起跳高，从上往下 |
| `high_rear` | high | 人立扬角 | branch | 后蹄站立，角高举 |

## 3. 线索（可视化提示，美术以小动画或图标表现，原创）
| 线索 id | 文字 | 指向 | 可做假动作 | 说明 |
|---|---|---|---|---|
| `head_down` | 头压得很低 | low | 是 | |
| `hoof_scrape` | 前蹄刨地 | low | 是 | |
| `tail_flat` | 尾巴放平 | mid | 否 | 真线索，不会伪装 |
| `eyes_forward` | 眼睛直视前方 | mid | 是 | |
| `hind_bend` | 后腿深蹲 | high | 是 | |
| `ears_up` | 耳朵竖起 | high | 否 | 真线索，不会伪装 |
| `wool_puff` | 羊毛炸起 | 无（纯干扰） | — | 只在 4–5 级出现 |
| `horn_glint` | 角尖闪光 | 该角形 `win` 所克的角度 | 是 | 暗示对手"想打克制"，高段位作为诱饵 |

**假动作规则：** 一条可伪装的线索以概率 `fakeChance` 被替换成指向错误角度的同类线索。`tail_flat` 和 `ears_up` 永远是真的，玩家学会后能"看穿"，形成可学习的深度。这正是"靠努力能赢"，和随机运气类玩法的区别。

## 4. 难度分级
| 级 | 线索数 | 假动作概率 | 观察时间 | 必含真线索 | 干扰线索 | 用途 |
|---|---|---|---|---|---|---|

## 5. 结算（接入 main.js 的 clash）
现有公式：`pp = 20 + pow + bonus + timing*30 + spd*0.3`，`ps.win === e.ang` 时 ×1.3。
新增：
- **预判命中**（`guess === e.ang`）：玩家力量 × `guessMul`（默认 1.3），并且抵消对手对你的角形克制（`readCancelsCounter = true`）。
- **预判落空**：没有惩罚（`missMul = 1.0`）。
- **总倍率上限** `maxMul = 1.6`，避免"克制 + 预判"叠加到 1.69 后过于碾压。
- 超时未选：视为落空。
- AI 也会预判：按 `aiReadAcc` 的概率猜中玩家角度。命中时同样获得 guessMul。玩家可以选择"不亮架势"，这一招留给 PvP，第一期不做。
- 原型的蓄力题（bonus）保留，作为第二个益智环节；擂台模式可以关掉，改由 `quizEnabled` 配置。

所有数值都在 clues.json 的 `tuning` 里，可以直接调。
