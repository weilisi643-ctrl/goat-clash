# 03 程序用 JSON 数据格式

示例文件在 data/ 目录下，都是 UTF-8 编码的合法 JSON。在原生小游戏里可以用 `JSON.parse(wx.getFileSystemManager().readFileSync('design/data/clues.json','utf8'))` 读取，也可以改成 `.js` 后 `module.exports` 导出。字段和原型对齐：`look{wool,woolColor,horn,hornColor}`、`ang: low|mid|high`、`horn.win`。

## clues.json
| 字段 | 类型 | 说明 |
|---|---|---|
| tuning.guessMul | number | 预判命中时的力量倍率，默认 1.3 |
| tuning.missMul | number | 预判落空时的倍率，默认 1.0 |
| tuning.counterMul | number | 原型的角形克制倍率 1.3 |
| tuning.maxMul | number | 倍率叠加上限 1.6 |
| tuning.readCancelsCounter | bool | 命中时抵消对手对你的角形克制 |
| tuning.quizEnabled | bool | 是否保留原有的蓄力题 |
| stances[] | {id, ang, name, horns[]} | 架势；horns 是常用这个架势的角形 |
| clues[] | {id, text, ang, fakeable, noise?, icon} | ang 为 null 表示纯干扰；"$hornWin" 表示取对手 `horn.win` 的值（鹿枝角为 none 时不出这条） |
| levels[] | {lv, clueCount, fakeChance, observeSec, mustHaveTrue, noise} | 难度 1–5 |

生成线索的伪代码：取对手真实 `ang`，从 `ang` 相同的线索里抽 `clueCount` 条。每条 fakeable 的线索按 `fakeChance` 的概率换成其他角度的线索。`mustHaveTrue` 为真时，至少保留一条 fakeable=false 的真线索。最后追加 `noise` 条干扰线索。

## champions.json
| 字段 | 说明 |
|---|---|
| resetHourUTC8 | 每日刷新的小时（北京时间），值为 5 |
| startDate | 第 1 天对应的日期；第 N 天的 dateKey = startDate + N−1 |
| fallback | 7 天轮完后的策略："procedural" 表示用 seed 生成 |
| freeTries / adExtraMax | 每日免费次数 / 激励广告追加次数上限 |
| days[].look | 擂主外观，和原型的 st.look 结构相同 |
| days[].stancePref | 擂主偏好的架势 id 列表 |
| days[].stages[].clueLv | 线索难度等级 |
| days[].stages[].ai | timingHit（完美时机概率）、readAcc（预判玩家角度的准确率）、counterPick（针对玩家角形选角度的概率）、powBonus（替代原型 `Math.random()*25+5`）、hpBonus |
| days[].stages[].allowedHorns | 挑战者可用的角形，null 表示不限 |
| days[].cardId | 守擂成功获得的图鉴卡 |

## factions.json
`changeCooldownDays`、`rankBy:"perCapita"`、`score{base,hpPctMul,readRateMul,dailyCapPerUser}`、`factions[]{id,name,flag}`、`rewards`（只有青草币、图鉴、称号、头像框）。

单次守擂得分 = `min(cap − todayScore, base + hpPct*hpPctMul + hits/guesses*readRateMul)`，四舍五入。

## progress.example.json（玩家每日进度，存云数据库，本地只缓存）
`uidHash`（openid 的哈希，不存明文）、`dateKey`、`faction`（null 表示未选）、`factionChangedAt`、`showProfile`（是否已授权实名展示，默认 false）、`tries{free,used,adGranted,adMax}`、`stage1Won/stage2Won/defended`、`todayScore/weekScore/defendDays`、`titles[]/cards[]/grass`、`readStats{guesses,hits}`、`history[]`。

**校验在服务端做**：次数、广告发放、得分都由云函数计算，客户端上报的只是操作结果，防止作弊。

## clash 接入示例
```js
var T = CLUES.tuning;
var mulP = 1, mulE = 1;
if (ps.win === B.e.ang) mulP *= T.counterMul;
var hit = B.p.guess === B.e.ang;
if (hit) mulP *= T.guessMul;
if (es.win === B.p.ang && !(hit && T.readCancelsCounter)) mulE *= T.counterMul;
if (B.e.readHit) mulE *= T.guessMul;  // AI 按 ai.readAcc 掷骰
pp *= Math.min(mulP, T.maxMul);
ep *= Math.min(mulE, T.maxMul);
```
