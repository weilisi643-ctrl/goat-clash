## 模拟模型
- 公式完全照 `main.js clash()`（REASONING_ENABLED=false、QUIZ 关）：
  玩家 `pp = 20 + 角pow + timing×30 + 毛spd×0.3`，`timing = 1-|meter-0.8|/0.8`；
  擂主 `ep = 20 + 角pow + powBonus + eT×30 + 毛spd×0.3`，`eT = 命中?1:U(0,0.7)`；
  玩家角形克制擂主角度 ×1.3，擂主角形克制玩家角度 ×1.3；伤害 `|pp-ep|+8`；体力=100+毛hp(+hpBonus)，三局两胜。
- **普通玩家**（假设）：按点偏差 ~N(0, 0.15 条长)，蓬松毛，限定角里随机选，70% 记得避开擂主克制角度。
- **完美玩家**：timing=1，最优羊毛+角形，总避开克制。
- 每格 6000–8000 局。“整关” = 第1场胜率 × 第2场胜率（单次挑战）。

## 2. 对手力量公式
确认实现是：`eT = random<timingHit ? 1 : random×0.7`，再 `×30`。可以保留。
注意：玩家没打准时是连续值（可低到 0），擂主没中的平均 0.35，二者口径不同但不影响平衡，数值已按此公式调。

## 3. 擂主角度要不要隐藏
**结论：现公式下隐藏与否对胜率没有影响。**原因：
- 擂主克制玩家只看 `擂主角形.win === 玩家角度`，擂主角形开局就可见，所以玩家避开靠的是看角形，不是看角度；
- 玩家克制擂主看 `玩家角形.win === 擂主角度`，但角形开战前已定，对战中看到角度也改不了。
模拟里玩家选角度只依据擂主角形，不读擂主角度，所以公开和隐藏按同一结果计算（公式里角度信息本身不产生收益）。
**建议**：第1场公开（教学），第2场隐藏、改为每次起跳后揭晓（`angleReveal: "hidden"`，增加悬念，不改数值）。
如果想让“读角度”真正有用，需要改规则（例如克制改为比较双方角度高低），那属于新玩法，要重新调数值。

## 4. 牧场积分新公式（替换 base + hpPct + 猜中率）
```
score = round( 8 + 6×timingAvg + 4×hpPct + (第2场 2:0 ? 2 : 0) )   // 只在第2场守擂成功时计，范围 8–20
每日上限 dailyCapPerUser = 20（不变，等于单次满分）
```
- timingAvg：第2场玩家所有起跳 timing 的平均值（0–1），需在 `jump()` 里累加 `B.timingSum/B.jumps`；
- hpPct：结束时剩余体力比例（现有字段）；
- 2:0 零封 +2（“顺利度”）。
factions.json 建议字段：`"score": {"base":8,"timingMul":6,"hpPctMul":4,"flawlessBonus":2,"dailyCapPerUser":20}`，`readRateMul` 删除。
`onStageEnd` 的 info 新增 `timingAvg`、`roundsLost`。
