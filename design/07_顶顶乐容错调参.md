# 07 顶顶乐容错调参（2026-10-28）

程序实测（σA=2°、σP=0.03）基线过关率过低。本方案**不改物理核心**，只放大草堆、微调草堆位置、略降部分参考解力度、放宽少数关 maxShots，并加 UI 层力度/角度吸附。

产出文件：`design/data/levels.v2.json`（**不要覆盖**正在用的 `levels.json`）。擂主 `champions` **本次不改**，上线后用 `timings[]` 埋点再校准。

## 1. 目标过关率（σA=2°、σP=0.03）

沿用程序建议曲线（合理，教学关高、反弹/连锁关低）：

| 关 | 目标 | 说明 |
|---|---|---|
| L1 | ≥0.70 | 直线教学 |
| L2–5、L8 | ≥0.35 | 偏难档 |
| L6 | ≥0.40 | 睡羊一顶，略高于偏难 |
| L7、L9、L10 | ≥0.20 | 很难档（多目标/一顶连锁/综合） |

**主指标用「自适应过关率」**：玩家每顶之后会按新站位重瞄，而不是机械复读参考解。盲目复读（blind）会严重低估多步关（L2/4/7/10）。

## 2. 全局措施（UI，不改 `ddl_physics.js`）

| 项 | 数值 | 实现位置 | 说明 |
|---|---|---|---|
| 草堆半径 | 已写入 v2 各关 `hays[].r`（相对 v1 +12～+30） | 只换 JSON | 优先手段；视觉上草堆更大即可 |
| 力度吸附 `powerSnap` | **±0.05**，档位 `0.5/0.6/0.7/0.8/0.9/1.0` | `ddl.js` / `main.js` 开火前 | `aimPower` 若距最近档 ≤0.05 则吸到该档。默认开 |
| 角度吸附 `angleSnap` | **±3°** | 开火结算前 | 见下规则。默认开，设置可关 |
| 瞄准辅助开关 | 默认开 | 设置页 | 同时控制角度吸附；力度吸附建议常开 |

### 角度吸附规则（务必按此实现）

1. 开火前，用当前 `start` 分别算到：场上每个**可推物件**（`type ≠ rock` 且 alive 且未进草堆）中心、每个草堆中心的方位角。
2. 取与 `aimAngle` 夹角绝对值最小的那个方向；若 `|Δ| ≤ 3°`，则把 `aimAngle` 设为该方向。
3. **L3、L8 关闭角度吸附**（`level.assist.angleMagnet = false`）。这两关要借墙/偏角，吸到物件中心会拉歪。v2 里已写好。
4. **不要**做「吸附到参考解角度」——那只是蒙特卡洛理想模型，真机没有上帝视角。

伪代码：

```js
function applyAssist(G) {
  // power
  var notches = [0.5,0.6,0.7,0.8,0.9,1.0], best = G.aimPower, bd = 1;
  notches.forEach(function (n) { var d = Math.abs(G.aimPower - n); if (d <= 0.05 && d < bd) { bd = d; best = n; } });
  G.aimPower = best;
  // angle
  if (G.lv.assist && G.lv.assist.angleMagnet === false) return;
  if (!aimAssistOn) return;
  var sx = G.lv.start.x, sy = G.lv.start.y, bestA = null, bestD = 4;
  function consider(x, y) {
    var a = Math.atan2(sy - y, x - sx) * 180 / Math.PI; if (a < 0) a += 360;
    var d = Math.abs(((G.aimAngle - a + 180) % 360) - 180);
    if (d <= 3 && d < bestD) { bestD = d; bestA = a; }
  }
  G.state.forEach(function (b) {
    if (!b.alive || b.inHay || b.static || b.type === 'rock') return;
    consider(b.x, b.y);
  });
  G.lv.hays.forEach(function (h) { consider(h.x, h.y); });
  if (bestA != null) G.aimAngle = bestA;
}
```

### 4.2 对照：盲目复读参考解（会低估）

### 4.3 与程序数字的差异

- 基线（v1、无吸附）本模拟与程序一致，物理已对齐。
- 程序若只测「固定参考解 + 噪声、不重瞄」，会得到接近 blind 的数字，多步关仍会显得很难；**请同时看自适应指标**，或让测试脚本在失败步后允许重瞄。
- 若真机仍偏难：优先再 +4～8px 草堆半径（L3/L8/L10），不要先动物理。
